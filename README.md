# 우리두리사회적협동조합 문서관리시스템

협동조합 및 연계 기관·교육 현장을 위한 **통합 문서 · 계약 · 근태 · 보안 · 경영 관리 시스템** (MVP)

**바로 사용** → https://jake12733.github.io/wooridoori-dms/

처음 접속하면 **최초 설정** 화면에서 최고 관리자(대표) 계정을 만들고, 실장·직원 계정은 최고 관리자가 [인사·계정 관리]에서 이메일로 발급합니다. 샘플 데이터는 없습니다.

## 주요 기능
- **대표·관리자 동일 최고 권한**: `happydrawing2@naver.com`=대표(ceo), `yunt59894@gmail.com`=관리자(admin)로 이메일 고정(DB 값과 무관), 그 외는 DB role, 미지정은 staff. 최고 권한은 대시보드·결재·대표 전용·계정 관리·계약서·근태 통계·다운로드 전부 가능
- **직원 화면 미리보기**: 대표·관리자가 실제 권한은 유지한 채 직원/실장 화면으로 전환해 확인 (미리보기 중 저장·발송 차단)
- **오피스형 에디터 + 원클릭 발송**: 엑셀형(#1D6F42)·워드형(#2B579A)·한글형(아이보리) 리본, 발송 대상(직급/직원 다중) 선택 후 원클릭 저장·발송, 알림함에 누가·누구에게·어떤 문서·몇 시 기록
- **4단계 직급 자동 분기**: 'ceo'(대표) · 'admin'(관리자) · 'manager'(실장) · 'staff'(직원). 로그인 시 DB의 직급을 조회해 전역 상태로 유지하고, 직급에 맞는 메뉴만 표시(대표=대시보드 시작, 그 외=통합 문서함 시작). 대시보드·결재·보완·🔒 대표 전용(경영·매출 장부, 보안 폴더)은 대표만, 직접 주소 접근도 차단·기록
- **초간편 문서함**: 전체 / 인사·직원 / 수업·운영 / 회계·정산 / 🔒 대표 전용, 요약 카드(결재·확인 필요 / 보완 요청 / 전체), 5열 목록, [+ 문서 등록] 하나로 직접 작성·파일 올리기
- **1초 근태 체크**: 직원은 큰 버튼 5개(출석·지각·병가·휴가·대강)+사유, 등록 후 삭제 불가. 대표는 요약 카드·직원별 표에서 수정·승인. 타 직원 기록·통계는 데이터 API 단계에서 대표 외에 반환하지 않음
- **문서 유출 방지(DLP)**: 최고 관리자(ADMIN) / 실장(MANAGER) / 직원(STAFF) / 비활성(RESIGNED). 실장·직원은 문서 작성·열람만 가능하고 파일 다운로드·PDF/엑셀 내보내기·우클릭·복사(Ctrl+C)·인쇄(Ctrl+P)가 차단됨. 열람 화면에 이름·이메일·현재 시간(초 단위) 반투명 워터마크
- **계정 비활성화(퇴사 처리)**: 모든 세션 즉시 만료 → 열린 화면 강제 로그아웃, 재로그인 차단
- **퇴사자 통제**: 미결 문서 인수인계 점검 → 확정 즉시 로그인 차단·세션/권한 회수 → 계약서·근태·정산 기록을 대표 전용 보관 DB로 분리
- **감사 로그**: 열람 시각, 수정 버전(v1, v2…), 원클릭 발송, 승인/반려, 반출·차단, 퇴사 권한 회수 자동 기록
- **무료 웹 오피스**: 엑셀형(x-spreadsheet + SheetJS, xlsx/csv), 워드형(Quill 2, docx 가져오기·PDF 출력), 한글(rhwp WASM, HWP/HWPX), 양식 템플릿 보관함
- **원클릭 발송 · 보완 워크플로우**: 프리셋 발송, PENDING → REVISION_REQUIRED → RESUBMITTED → APPROVED(잠금), 타임라인
- **필수 서류 체크리스트**: 정규직/위촉강사 세트, 미제출·보완 대기·완료 자동 집계
- **계약서**: 근로·위촉계약서, 캔버스 전자서명, 대표 전자 직인, 잠금, D-30/14/7 만료 알림, 갱신 초안
- **근태**: 출퇴근, 근무·지각·조퇴·병가·휴가·대강, 월별 집계
- **대표 대시보드**: 매출·지출·순수익, 전 직원 근태/계약/서류 현황, 원클릭 런처
